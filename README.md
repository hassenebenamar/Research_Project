# Study of Evolution in Virtual Worlds

This repository contains the research project for my **M1 thesis**, exploring the study of evolution in a virtual world using **Unreal Engine 5** and **C++**.

The project applies **Genetic Algorithms** and principles of **Artificial Life simulation**, using a simplified model of agents’ DNA to investigate emergent behaviors in a controlled digital environment.

## Publications

- **Master Thesis**: Available on [HAL]([https://hal.science/tel-04471795](https://hal.science/tel-04471795v1)) (ID: *tel-04471795*).  
- **Conference Paper**: Presented at the WSCG Conference 2024 in Plzeň, Czech Republic.
